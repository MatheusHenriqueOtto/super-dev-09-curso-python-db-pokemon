# Projeto de batalhas de pokemons

## Instalação

Criar env: `py -m venv env`

Ativar env Windows: `env\Scripts\activate`

Ativar env Linux: `source env/bin/activate`

Instalar uma dependencia: `pip install <nome>`

Salvar quais dependencias o projeto tem: `pip freeze > requeriments.txt`

Instalar todas as dependencias: `pip install -r requeriments.txt`

Desativar env: `desactivate`

Flux de novo projeto:
```shell
py -m venv env
env\Scripts\activate
pip install "fastapi[standard]"
pip freeze > requireents.txt
```
